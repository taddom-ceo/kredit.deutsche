# kredit.deutsche — Website

Next.js (App Router, TypeScript, Tailwind) marketing site. Public, no
login/auth. Dark-navy design with an interactive credit calculator and a
DE/EN language toggle.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Push to GitHub, then import the repo on [Vercel](https://vercel.com/new).
